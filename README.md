# Flip Card Game

A card-matching memory game. Flip cards two at a time, remember where
each one is, and clear the board by finding all the matching pairs.

## Overview

Flip Card Game is a simple memory game built as a Java project. Cards are
laid face down; the player flips two cards per turn, and matching pairs
stay revealed until every pair has been found.

## How to Play

1. The board starts with all cards face down.
2. Flip two cards per turn.
3. If the cards match, they stay face up.
4. If they do not match, they flip back and you try again.
5. The game ends when all pairs have been matched.

## Tech Stack

- Java
- IntelliJ IDEA project structure

## Getting Started

### Prerequisites

- JDK 11 or later
- IntelliJ IDEA (recommended) or any Java IDE

### Run the Game

1. Clone the repository:

       git clone https://github.com/cuervo0102/Flip-Card-Game.git
       cd Flip-Card-Game
       git checkout cardBranch

2. Open the project folder in IntelliJ IDEA.
3. Locate the main class in `src/` and run it.
